# Adobe Illustrator MCP interface — preliminary reconstructed compatibility specification

**Status:** static reconstruction from native binaries; not an implementation and not a live protocol dump.

The schema metadata below is recovered directly from the embedded MCPToolkit registry. Fields that could not be structurally recovered are marked `UNKNOWN` in the JSON version.

Objects can be aligned relative to each other (selection bounding box) or to the active artboard. Alignment is single-axis: 'left'/'center'/'right' shift X only (Y unchanged); 'top'/'middle'/'bottom' shift Y only (X unchanged). Prefer this tool over manual MoveObjects calculations whenever you need to align edges or centers of multiple objects.

- **DistributeObjects** (`AlignmentTasks`, HIGH) — ALWAYS use this tool instead of manual MoveObjects offset math to CREATE or ADJUST equal gaps between 2+ objects \u2014 including improving/fixing/adjusting uniform tracking or letter-spacing in a wordmark/logotype/word made of separate letter objects. Not for pure repositioning of an already-spaced group (use MoveObjects instead, which preserves existing spacing). Only supports one uniform gap value for all objects, not unequal/proportional/ratio-based spacing (e.g. non-uniform kerning between specific letter pairs). Distributes objects evenly along an axis. If spacing is provided, objects are placed with that exact gap between them (2+ objects). If spacing is omitted, objects are distributed evenly within the total span from first to last (3+ objects required \u2014 pass explicit spacing instead for exactly 2 objects).

- **SetAppearance** (`AppearanceTasks`, HIGH) — Sets visual appearance and state properties (fill, stroke, opacity, blend mode, locked, hidden, overprint) on one or more objects in a single call. All properties are optional \u2014 only provided properties are changed. To remove fill or stroke, set fillColor='none' or strokeColor='none'. Supports batch operations via uuids array. fillColor/strokeColor overwrite the entire fill/stroke of the objects you name with one literal color, applied exactly \u2014 use this tool whenever the request names a literal target color or color space, e.g. a hex, a Pantone/spot name, 'all red', or 'grayscale'/'black and white', at any scope from one object to a whole illustration ('make this illustration blue'). For 'grayscale'/'black and white' on multi-colored artwork, don't apply one flat gray to everything (that flattens the tonal variation) \u2014 read each object's current color via GetVisualAppearance, derive a gray from its luminance, and call once per distinct gray with the matching uuids. For an open-ended palette/theme/mood change with no fixed target color ('make it warmer', 'recolor to autumn', 'reduce to 2 colors'), use RecolorArtwork instead. NOTE: This tool handles flat colors only. For gradient fills or strokes \u2014 or to change angle, stops, or type on an existing gradient \u2014 use SetGradient instead. Providing a flat fillColor on an object with a gradient fill will replace the gradient with a flat color. Never invent, guess, or autocomplete swatch names. Text frames: fill/stroke color, paint toggles, overprint, and stroke-style properties apply to characters via the text engine; opacity and blend mode behavior is unchanged. IMPORTANT: Set locked=false or hidden=false ONLY when the user explicitly asks to unlock/show objects or explicitly references locked/hidden state (e.g., 'unlock layer X', 'show the hidden group', 'delete the locked layer'). Generic requests like 'delete all', 'move everything', 'rotate the shapes', or 'place/add X in layer Y' do NOT grant permission to unlock/unhide first, even if that's the only way to fulfill the request \u2014 ask the user instead. When a requested fill/stroke/paint change can't be applied to an object's type, that object is reported in skipped_objects (with skipped_count and a per-object reason), NOT failed_objects; opacity, blend mode, locked, and hidden still apply. Symbol instances are the common case \u2014 the response additionally carries a symbol_link_guidance field explaining the symbol link must be broken first. Response shape: {success, details, success_count, fail_count, failed_objects?, skipped_count, skipped_objects?, symbol_link_guidance?}.
  - Input: `uuids` (array|string; required), `fillColor` (string|object; optional), `strokeColor` (string|object; optional), `strokeWeight` (number; optional), `strokeWeightDelta` (number; optional), `strokeCap` (string; optional), `strokeJoin` (string; optional), `strokeDash` (array|number; optional), `opacity` (number; optional), `blendMode` (string; optional), `locked` (boolean; optional), `hidden` (boolean; optional), `overprintFill` (boolean; optional), `overprintStroke` (boolean; optional)
  - Result: {}
  - Provenance: raw lines 102-264; offset 0x2e7bbc.

- **ScaleArtboards** (`ArtboardTasks`, HIGH) — Scale or resize artboards. Do NOT use this tool for named preset requests like 'iPhone X', 'A4', 'Instagram Story', 'HDV/HDTV 720' \u2014 call GetArtboardProperties to look up dim1_pt/dim2_pt, decide which to use as width/height based on the artboard's current orientation or user request, then call SetArtboardProperties with presetName or use this tool with mode='absolute' and the chosen dimensions. The 'mode' parameter controls how scaleXValues/scaleYValues are interpreted:   mode='factor': values are multipliers (1.0=no change, 2.0=double, 0.5=halve).   mode='absolute': values are target width/height in points (e.g. 500 means 500pt). Prefer mode='absolute' when the user gives exact dimensions (e.g. '500 by 700 points'). Scaling is applied around per-artboard anchor points (defaults to 'center'). Valid anchors (hyphenated): 'top-left','top-center','top-right','center-left','center','center-right','bottom-left','bottom-center','bottom-right'. Use anchors to pin a specific corner or edge during resize, e.g. anchors=['bottom-right'] keeps the bottom-right corner fixed while the artboard grows/shrinks from the top-left. Artwork scales with the artboard by default (scaleContent=true); set scaleContent=false to resize the artboard only. When scaleContent=true, artwork preserves its own aspect ratio by default (maintainAspectRatioOfContent) even when the artboard itself is resized non-uniformly - see maintainAspectRatioOfContent. All provided arrays must match the length of artboardIndices. Locked artboards are skipped unless force=true. Must stay within the canvas \u2014 see ListArtboards' canvas_bounds.

- **Extract** (`ExtractTasks`, HIGH) — Extract named resources ('what': colors, swatches, symbols, brushes, graphic-styles, character-styles, or paragraph-styles) from a document at an absolute file path into the current document. 'filters' is an optional comma-separated list narrowing results; allowed values depend on 'what' (brushes: used,unused,calligraphic,scatter,art,bristle,pattern; symbols: used,unused,static,dynamic; graphic-styles/character-styles/paragraph-styles: used,unused; colors/swatches: used,unused,process,global,spot,solid,pattern,linear-gradient,radial-gradient,gradient). - **FindObjects** (`FilterOperationTasks`, HIGH) — Batch query and update tool for object properties (color, weight, font, text content). Prefer over structural browsing when you need bulk data (e.g. every object's color for grouping or auditing) \u2014 omit matchCriteria, pass returnFields:['color'] to get all fill/stroke values in one call without walking the hierarchy. Also finds objects by exact criteria (not fuzzy/visual categories \u2014 'lines' aren't a distinct type from other paths, see 'objectTypes') and optionally writes setProperties (fillColor/strokeColor/strokeWeight) onto every match in the same call. setProperties can never write text content (use ReplaceText) or font (use ReplaceFont). Omit 'setProperties' to run in query mode: matches are reported (shape controlled by 'returnFields') and nothing is written.
